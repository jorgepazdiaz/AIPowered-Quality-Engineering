# WBS, estimación y riesgos de proyecto

**Sesión:** S04

```text
Rol: QA Manager con experiencia en {dominio}.
Contexto: proyecto de {semanas} semanas para asegurar la calidad de {app}.
Responsable: 1 persona, {h} h/semana. Funcionalidades priorizadas: {lista}.

1. Construye la WBS de actividades de QA (máx. 3 niveles).
2. Estima cada actividad con 3 puntos (optimista / probable / pesimista) y PERT.
3. Lista 8 riesgos de proyecto: probabilidad, impacto, mitigación, responsable.
4. Compara el esfuerzo total con tu capacidad y propone recortes si excede.
5. Indica supuestos y datos que te faltan.
Formato: tablas Markdown.
```

## Notas de uso
- Reemplazar las variables `{…}` con contexto real (sin datos sensibles).
- Ejecutar 2-3 veces y comparar; validar siempre la salida.
