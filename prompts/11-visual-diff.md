# Triage multimodal de un diff visual

**Sesión:** S13

```text
Adjunto 3 imágenes de {pantalla}: 1) baseline 2) actual 3) diff.
Actúa como QA visual:
- ¿Qué cambió? Describe cada diferencia y su zona.
- ¿Parece intencional (rediseño) o un defecto?
- Severidad (bloqueante, mayor, menor, cosmético) según impacto en el usuario.
- Problemas de accesibilidad visibles (contraste, texto cortado, foco, tamaño de objetivos).
Formato: tabla Markdown. La aprobación del baseline la hace una persona.
```

## Notas de uso
- Reemplazar las variables `{…}` con contexto real (sin datos sensibles).
- Ejecutar 2-3 veces y comparar; validar siempre la salida.
