# Roadmap de mejora de madurez QE

**Sesión:** S01

```text
Actúa como consultor de Quality Engineering.
Contexto: evaluamos la madurez QE de una organización con esta matriz (niveles 1-4):
{matriz_con_evidencias}

Tarea:
1. Identifica las 2 dimensiones más críticas y explica por qué.
2. Propón un roadmap de 3 mejoras priorizadas para los próximos 6 meses.
   Para cada una: objetivo, acciones, esfuerzo (S/M/L), métrica de éxito.
3. Indica supuestos y riesgos del roadmap.
Restricción: recomendaciones realistas para un equipo de {n} personas.
Formato: tablas Markdown.
```

## Notas de uso
- Reemplazar las variables `{…}` con contexto real (sin datos sensibles).
- Ejecutar 2-3 veces y comparar; validar siempre la salida.
