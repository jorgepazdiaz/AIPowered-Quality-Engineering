# Análisis de una historia de usuario

**Sesión:** S01-S02

```text
Actúa como QA Lead senior de {dominio}.
Analiza la siguiente historia de usuario:

{historia}

1. Lista ambigüedades y preguntas concretas para el PO.
2. Identifica riesgos de negocio y técnicos (impacto 1-5).
3. Propón criterios de aceptación en formato Dado / Cuando / Entonces.
4. Señala qué supuestos hiciste.
No inventes reglas: si falta información, pregúntala.
Responde en tablas Markdown.
```

## Notas de uso
- Reemplazar las variables `{…}` con contexto real (sin datos sensibles).
- Ejecutar 2-3 veces y comparar; validar siempre la salida.
