# Estrategia QE encadenada (contexto → propuesta → crítica)

**Sesión:** S06

```text
Paso 1 · Contexto
"Esta es la arquitectura de {app}: {diagrama}. Riesgos priorizados: {matriz}.
 Responsable: 1 persona, {semanas} semanas, herramientas: Playwright, GitHub Actions, IA."

Paso 2 · Propuesta
"Propón una estrategia QE por componente: niveles y tipos de prueba, herramientas,
 automatización, ambientes y datos, uso de IA (casos de uso + controles) y quality gates.
 Justifica cada decisión con un riesgo."

Paso 3 · Crítica
"Actúa como auditor: ¿qué está sobredimensionado, qué falta y qué es poco realista
 para una persona en este plazo? Devuelve la versión corregida."

Paso 4 · Volcar el resultado en templates/estrategia.md y revisarlo como equipo.
```

## Notas de uso
- Reemplazar las variables `{…}` con contexto real (sin datos sensibles).
- Ejecutar 2-3 veces y comparar; validar siempre la salida.
