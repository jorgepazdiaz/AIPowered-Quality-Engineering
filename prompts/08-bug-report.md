# Bug report desde notas sueltas

**Sesión:** S03, S21

```text
Convierte estas notas en un bug report profesional:
{notas, logs, capturas descritas}

Estructura: Título (componente + síntoma + condición) · Ambiente · Precondiciones ·
Pasos para reproducir (mínimos y numerados) · Resultado esperado · Resultado actual ·
Severidad y prioridad (justificadas) · Evidencia · Notas.
Si falta información para reproducir, lista qué preguntar. No inventes datos.
```

## Notas de uso
- Reemplazar las variables `{…}` con contexto real (sin datos sensibles).
- Ejecutar 2-3 veces y comparar; validar siempre la salida.
